### 🏍️ MotoFix
**Online Motorcycle Parts & Service Ordering System**

A full-stack web app for motorcycle repair shops — customers can order parts, book mechanics, and track their service in real time. Powered by an AI chatbot.

**Stack:**
`Node.js` · `Express` · `MySQL` · `JWT` · `Groq API` · `HTML/CSS/JS`

</td>
<td width="50%" valign="top">

**✅ Features**
- 🔐 JWT Authentication + bcryptjs
- 🤖 AI Chatbot (Groq LLaMA)
- 📧 Email OTP Verification
- 📦 Product Ordering & Inventory
- 🔧 Mechanic Booking System
- 📊 Admin Dashboard
- 🚚 Real-time Order Tracking
- 🖼️ Image Upload via Multer
- 📍 Address Management
- ⭐ Reviews & Customer Feedback

</td>
